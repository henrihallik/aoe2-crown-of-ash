CROWN OF ASH FEATURE ISOLATION
==============================

OBSOLETE: DO NOT USE THESE RESULTS FOR FEATURE ISOLATION.

Every file starts with v1.0.2, which was later confirmed to crash when a scout
reveals terrain outside the starting area. A T-test crash can therefore come
from the shared baseline rather than the restored feature. Use the newer
terrain-isolation tests first.

These files are diagnostic maps, not releases. Each one starts with the v1.0.2
script and restores only the feature named in its filename.

INSTALL
-------

1. Copy all .rms files from this archive into:

   %USERPROFILE%\Games\Age of Empires 2 DE\<player-id>\resources\_common\random-map-scripts\

2. Fully restart Age of Empires II: Definitive Edition.
3. The diagnostic maps appear under Custom and start with "Crown Ash T".
4. No PNG files are needed for these tests.

FAST SCENARIO EDITOR TEST
-------------------------

Test T01 through T10 separately:

1. Generate a new map using the named diagnostic map.
2. Press Test.
3. Move a unit and wait at least 30 seconds.
4. Record PASS or CRASH below.

If a test crashes, report its exact T-number and stop. If T01 through T10 all
pass separately, test T11. T11 combines every restored feature except
guard_state and detects a feature interaction.

SKIRMISH CONFIRMATION
---------------------

For every test that passes the editor, use the same Skirmish settings that
previously crashed v1.0.1. Let it run past 3:00 game time. Record the exact crash
time if it fails.
